# Release Notes: v1.0.0

Cyber Command Center v1.0.0 is the first release-ready local/private SOC lab package.

- FastAPI dashboard backend, SQLite persistence, API authentication, rate limits, structured redacted logging, and safe error responses.
- Network Monitor, APK Guard, WebSec Lab, HashLab, detection rules, alerts, events, timeline, and lab risk scoring.
- Explicit managed-device pairing, revocation, credential rotation, offline monitoring, and safe-action allowlists.
- Lightweight Windows reference agent with DPAPI credential protection and bounded reconnect behavior.
- Android dashboard with configurable LAN/tunnel endpoint and bearer-token handling.
- Release scripts for setup, startup, health checks, database initialization, verified backup, and explicit restore.

External validation intentionally remains separate: physical Android-device validation and a real private VPN/tunnel deployment are operator tasks.
